# Linux Admin Toolkit

A collection of Linux system administration and automation scripts built using Python.

## Features

- CPU Monitoring
- Memory Monitoring
- Disk Monitoring
- System Information
- User Management
- Log Analysis

## Project Structure

```
linux-admin-toolkit/
├── admin/
├── docs/
├── monitors/
├── screenshots/
├── README.md
├── requirements.txt
└── LICENSE
```

## Requirements

- Python 3.10+
- Linux (Ubuntu recommended)

## Installation

```bash
pip install -r requirements.txt
```
